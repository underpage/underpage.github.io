# Knowledge
: 일반적으로 지식이란 학습이나 경험을 통해 얻은 정보가 체화되어 상황을 이해하고 문제를 해결하는 데 쓸 수 있는 앎의 총체를 의미하며 관점에 따라 다르게 해석됨  
: 공학 관점에서 지식은 기계가 다룰 수 있게 표현된 앎과 이를 추론해 이끌어 낸 앎을 함께 의미함  
: 이를 위해 지식을 표현하고 공유하는 기술과 방법이 필요함  

```
명시된 지식 (입력)
    | 추론 (액션)
도출된 지식 (결과)
```
